# StealthOverlay — Audio Transcription & Real-Time AI Copilot Setup

## 🔍 Audit & Technical Debug Report (Solving the Missing Tab Audio Detection)

### 🚨 Root Causes Identified in Diagnostic Audit:
1. **WebSpeech API Isolation in Content Scripts**:
   - `webkitSpeechRecognition` inside Chrome extension content scripts ONLY captures physical hardware microphone input (laptop mic), NOT the internal digital audio stream generated by HTML5 `<audio>` tags (like ElevenLabs, Google Meet, Zoom).
   - Furthermore, Chrome security policies abort WebSpeech instances started in content scripts without a user gesture frame (`WebSpeech ended | active: true` loop).
2. **Missing Wiring for Tab Audio Capture (`start_tab_capture`)**:
   - `background.js` and `offscreen.js` had the complete digital `chrome.tabCapture` engine ready, but `popup.js` was **never sending `start_tab_capture`** when activating listening!
3. **Hardcoded Model ID (`gemini-2.0-flash`) in `offscreen.js`**:
   - `offscreen.js` contained a legacy reference to `gemini-2.0-flash` (which Google retired), causing `offscreen.js` STT calls to return `HTTP 404`.

---

## 🛠️ Complete Solutions Implemented

1. **Digital Tab Audio Capture Integration (`popup.js` & `background.js`)**:
   - Clicking either the **Screen/Tab Audio Icon (Monitor)** or **Mic Icon** now fires `start_tab_capture` directly to `background.js`.
   - `background.js` creates the offscreen document and uses `chrome.tabCapture.getMediaStreamId()` to capture the **100% digital internal audio stream** from ElevenLabs / Google Meet / Zoom!
2. **Updated Model to `gemini-3.6-flash` in `offscreen.js`**:
   - Fixed the hardcoded model URL in `offscreen.js` to point to the active free tier model `gemini-3.6-flash`.
3. **Interactive Language Switcher Badge (`🌐 EN` / `🌐 ID`)**:
   - Added a 1-click language switcher badge right on the floating capsule for instant switching between English (`en-US`) and Indonesian (`id-ID`).

## Summary of Fixes & Updates

### 1. Hybrid Speech Recognition System (`popup.js`)
- **Native Browser WebSpeech Engine (`webkitSpeechRecognition`)**: Works **100% FREE out-of-the-box** without requiring any API key for microphone speech!
- **Real-Time Word Chips & Live Transcript**: As speech is spoken or played, text streams live onto word chips and the live transcript bar under the overlay pill.
- **Automatic AI Answer Pop-Up**: When sentence/speech completes (> 3 chars), it automatically calls `fetchAIAnswer(text)` and pops up the AI answer card with solution key points!
- **No Error Loops**: Fixed `SpeechRecognition error: aborted` by adding debounced restart logic (800ms) and preventing concurrent instance conflicts.

### 2. High-Accuracy Cloud STT (Groq Whisper / Gemini 2.0 Flash)
- **Groq Whisper API (`whisper-large-v3-turbo`)**: Ultra-fast (~150ms) speech-to-text. Auto-detected when API Key starts with `gsk_`.
- **Google Gemini API (`gemini-2.0-flash`)**: Audio transcription using inline base64 payloads. Auto-detected when API Key starts with `AIzaSy`.
- **OpenAI Whisper API (`whisper-1`)**: Supported when provider is set to `openai` or API Key starts with `sk-`.

### 3. Tab Audio Capture (Offscreen Document)
- Captures interviewee/speaker audio from video call tabs (ElevenLabs, Google Meet, Zoom Web).
- Audio chunks (4s) sent to local STT server (`http://127.0.0.1:8765/api/transcribe`) or Cloud API (Groq/Gemini).
- If no API key is saved, provides a direct clickable link right inside the overlay live transcript bar to open Extension Options.

## How to Test Right Now

1. **Reload Chrome Extension**:
   - Open `chrome://extensions` in Chrome.
   - Click **Reload** icon (🔄) on **StealthOverlay**.

2. **Test Microphone Voice Recognition (Free Out-of-the-Box)**:
   - Click the Microphone icon on the StealthOverlay bar.
   - Speak into your microphone (e.g. *"What is the difference between TCP and UDP?"*).
   - **Result**:
     - Words appear live on chips: `[What] [is] [difference] [between] [TCP] [UDP]`
     - Transcript line shows full text.
     - AI Answer Card automatically pops up with concise technical points!

3. **(Optional) Add Free Groq/Gemini API Key for High Precision**:
   - Right-click extension icon > **Options**.
   - Paste a free **Groq Key** (`gsk_...` from [console.groq.com](https://console.groq.com)) or **Gemini Key** (`AIzaSy...` from [aistudio.google.com](https://aistudio.google.com)).
